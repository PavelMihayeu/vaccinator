# Vaccinator

A Spring Boot service developed by **Endevity Labs** to manage vaccination appointments and send timely notifications to users.

## Features

- Schedule and manage vaccination terms
- Notify users of upcoming appointments
- RESTful API for integration with mobile/web applications
- Built with extensibility and reliability in mind

## Tech Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Validation
- Spring Actuator
- PostgreSQL (or your preferred DB)
- Docker (optional, for containerization)
- Gradle or Maven (build system)
